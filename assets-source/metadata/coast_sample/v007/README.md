# Coast sample v007 — более мягкие солнечные тени

Дата: 2026-09-10. Статус: ожидает художественной оценки.

Изменена только настройка света в Blender: угловой размер Coastal_sun увеличен с 0.018 rad (≈1.03°) до 4°. Края теней от высоких пальм мягче, тени у основания предметов сохраняют контакт. Это реальные полутени Cycles, без размытия/ретуши готовых PNG. Для финальных рендеров Cycles samples увеличены с 48 до 64; denoise сохранён.

Палитра, PBR-материалы, вода, геометрия, раскладка, мощность/цвет солнца, заполняющий свет, экспозиция +0.60 и Khronos PBR Neutral остаются из v006. Все пять камер повторяют v006. Образец конечный, длина 40 м; дополнительный композиционный вид частично перекрывает крона, основной игровой ракурс свободен.

Их повторный импорт и геометрический аудит уже выполнены для v006; в этой итерации GLB не изменялись. Проверки не отключались.
