# Проверка производительности

Аппаратные замеры ещё не выполнены. Успешный build, NullEngine и Playwright на Windows не подтверждают 60 FPS в Safari. Бюджеты из GAME_IMPLEMENTATION_PLAN.md не изменены.

## Текущий стенд

- Физика 60 Гц, максимум 4 догоняющих шага, 6 динамических и 5 статических тел.
- 30 мешей (включая 6 невидимых коллайдеров), 12 материалов после подготовки рендера; фактические значения доступны в отчёте.
- Canvas до примерно 1 Мп, DPR до 2; графический пресет фиксированный. Реального адаптивного качества ещё нет.
- Подготовка — загрузка Havok, создание сцены и готовность шейдеров; после сброса измеряется пересоздание сцены с уже загруженным WASM.
- Interval p95/p99 — интервалы активного render loop, CPU p95/p99 — работа JS и отправка рендера. GPU отдельно не измеряется.
- Снимки/JSON из Playwright сохраняются в test-results; они нужны для функциональной диагностики, не для аппаратной приёмки. В автотестах включён программный SwiftShader.

## Протокол на каждом устройстве

Проверить iPhone 16 Pro Max, iPhone 17 Pro, iPad 11-го поколения. Для каждого заполнить:

| Поле | Фактическое значение |
|---|---|
| Устройство | Не проверено |
| iOS/iPadOS и Safari | Не проверено |
| Версия/ревизия сборки и URL | Не проверено |
| Энергосбережение (выключено), заряд, подключение к питанию | Не проверено |
| Температура/нагрев, исходное состояние | Не проверено |
| Холодная загрузка: время, ошибки, объём передачи | Не проверено |
| Прогретая сцена: JSON после 30–60 секунд | Не проверено |
| 20 сбросов: JSON до и после, рост ресурсов | Не проверено |
| Пауза, фон 30 секунд, возврат без скачка времени | Не проверено |
| Альбомная/портретная ориентация и safe areas | Не проверено |
| 15–20 минут: интервалы, CPU, длинные кадры, нагрев | Не проверено |
| Итог и ссылка на сохранённые JSON | Не проверено |

«Тестовый толчок» используйте для повторяемой проверки контактов, затем «Сброс». Это не стресс-сценарий полной гонки с нитро. Его добавят на соответствующем этапе. Для оценки стабильности храните несколько JSON, поскольку распределение охватывает последние 1800 активных кадров; общие счётчики сохраняются до сброса.

Приёмка этапа 0 требует запуска production с Pages на всех трёх устройствах. Приёмка 60 FPS для готовой игры будет выполняться заново с настоящими ассетами и игровыми системами.
