# Фактический статус

Дата: 2026-09-09. Этап 0 реализован локально; аппаратная приёмка остаётся открытой.

## Сделано

- Создан Git-репозиторий (main), TypeScript/Vite, точные зависимости и lockfile.
- WebGL2 + Babylon Physics V2/Havok, локальный WASM; фиксированная дорога, 6 динамических кузовов и 5 статических тел.
- Физика 60 Гц, ограничение догоняющих шагов, интерполяция визуальных кузовов.
- Пауза/Esc, фон/потеря фокуса, портретное ограничение сенсорных устройств, resize, тестовый импульс, пересоздание сцены.
- Диагностика и экспорт JSON: версия, окружение, фиксированный scenario/seed, подготовка, разрешение, ресурсы, интервалы/CPU p95/p99 и длинные кадры.
- Ошибка загрузки Havok с повтором, отказ при отсутствии WebGL2, восстановление через перезагрузку при потере контекста.
- GitHub Actions для проверок и публикации Pages; runtime-лицензии включены в dist.
- Создан публичный репозиторий: https://github.com/testMovielucky/coastal-racer . Публикация ожидает выполнения workflow.

- Node: v24.19.0. npm: локальный 11.6.2. Blender **не проверялся** по просьбе заказчика.

- `tools/npm.ps1 run typecheck` — успешно; также выполняется внутри build.
- `tools/npm.ps1 run build` — успешно. `tools/check-build.mjs` проверил локальный WASM, относительные URL и состав dist. Примерно 3,73 МБ без сжатия, оценка gzip 1,06 МБ; это не замер сетевой передачи Pages. Vite предупреждает об основном чанке движка >500 КБ; предупреждение не скрыто.
- `tools/npm.ps1 test` — 7/7: часы при 30/60/120 Гц, предел догоняющих шагов, сброс остатка времени, статистика; реальный Havok WASM с падением на дорогу и передачей импульса; 20 циклов создания/освобождения миров.
- `tools/npm.ps1 run test:e2e` — 11 пройдено, 1 неприменимый тест ориентации пропущен для desktop. Chrome/SwiftShader на Windows; настольный и сенсорный портретный профили. Проверены production под /coastal-racer/, отсутствие внешних запросов, локальный WASM, выгрузка JSON, пауза/возврат, 20 сбросов без роста наблюдаемых ресурсов, потеря фокуса, ориентация/resize, ошибка HTTP 503 при загрузке WASM.
- Проверены снимки мобильной компоновки; камера скорректирована так, чтобы панель не закрывала шесть кузовов.
- Во время первого прогона найдена и исправлена преждевременная индикация готовности. Итоговые тесты прошли после исправления, отключений тестов не было.
